Questions

?
Does DASH collect anything about me?

No. There is no telemetry, no account and no advertising ID. History, bookmarks, notes and passwords stay in DASH's data folder on your device. The full list of connections is above.

Why does Windows warn me before running it?

The Windows build is not code-signed yet, and Windows warns about any unsigned program from a small publisher. You can read the source on GitHub before running it.

Is it really free?

Yes. DASH is open source under the GPL-3.0 license, made by Bibek Bista, an independent developer in Nepal. There are no paid tiers and no ads.

Can I sync between my laptop and phone?

There is no sync service, because that would mean your data sits on someone's server. Instead, export an encrypted backup on one device and restore it on the other.

Which engine does it use?

Windows runs on Chromium through Electron. Android uses the system WebView. Websites that work in Chrome work in DASH.

I found a bug. Where do I report it?

Open an issue on GitHub. Security problems go through the process described in the repository's SECURITY.md.
