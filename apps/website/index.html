Most browsers call home for analytics, sync and suggestions. DASH has none of that. Besides loading the pages you ask for, these are the only requests it can make, and each one is off by default or starts with something you do.

Ads and trackers, stopped first

Requests to known ad and tracking hosts are blocked before they load, so pages are faster and nothing watches you read. Turn blocking off for one site if it breaks.

HTTPS-only mode

DASH upgrades plain http addresses to https and warns you before opening a site that cannot be secured. On Android, certificate errors cannot be clicked away.

Installing on Windows

  1. Run the downloaded file.
  2. If Windows SmartScreen says it protected your PC, choose More info, then Run anyway. This appears because the build is not signed yet, not because anything was detected.
  3. Finish the installer, open DASH and pick your look and search engine.

Installing on Android

  1. Open the downloaded .apk from your notifications or Downloads.
  2. If asked, allow installs from this source, then go back and tap Install.
  3. Open DASH. You can turn the permission off again afterwards.

Questions people ask first

Does DASH collect anything about me?

No. There is no telemetry, no account and no advertising ID. History, bookmarks, notes and passwords stay in DASH's data folder on your device. The full list of connections is above.

Why does Windows warn me before running it?

The Windows build is not code-signed yet, and Windows warns about any unsigned program from a small publisher. You can read the source on GitHub before running it.

Is it really free?

Yes. DASH is open source under the GPL-3.0 license, made by Bibek Bista, an independent developer in Nepal. There are no paid tiers and no ads.

Can I sync between my laptop and phone?

There is no sync service, because that would mean your data sits on someone's server. Instead, export an encrypted backup on one device and restore it on the other.

Which engine does it use?

Windows runs on Chromium through Electron. Android uses the system WebView. Websites that work in Chrome work in DASH.

I found a bug. Where do I report it?

Open an issue on GitHub. Security problems go through the process described in the repository's SECURITY.md.
