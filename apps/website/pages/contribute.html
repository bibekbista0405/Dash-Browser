Report a problem

Open an issue on GitHub and say which version you use, whether it is Windows or Android, what you did and what happened. A screenshot helps. For a security problem, do not open a public issue: read the security page.

Ground rules

  • No telemetry or tracking, ever, and no new network connection unless the user starts it. If a feature needs one, it must be written down in the privacy documentation in the same change.
  • Real features only: no placeholder screens or invented data. If something is limited, the app and the docs say so.
  • Secure Electron defaults: context isolation on, no Node in renderers, every IPC channel validated.
  • Your contribution is licensed under GPL-3.0-only.

Run it yourself

npm install
npm run dev          # development
npm run typecheck
npm run lint
npm run build

The desktop app is in apps/desktop, shared logic in packages/browser-core, the Android app in apps/android and this website in apps/website. The full guide is CONTRIBUTING.md.

Pull requests

  1. Keep a pull request focused and describe how you tested it.
  2. Typecheck, lint and build must pass.
  3. Add a line to the changelog.
