First run

DASH opens a short welcome where you choose a theme and a search engine. On desktop you can also import bookmarks from a file on that screen. Later, Settings has the same choices and more: search suggestions, secure DNS, VPN or proxy, security, backups and import from another browser.

Privacy tools

  • Ads and trackers. Requests to known ad and tracking hosts are blocked before they load, so pages are lighter and fewer scripts watch you. If a site breaks, turn blocking off for that one site.
  • HTTPS-only. Plain http addresses are switched to https, and DASH warns you before opening a site that cannot be secured.
  • Private tabs. A private tab keeps its cookies, storage and cache apart and wipes them when the last private tab closes. If you set up a VPN, private tabs can connect it first.
  • Global Privacy Control and Do Not Track. Sent by default. You can turn it off in Settings. Websites decide whether to honour it.
  • Secure DNS, VPN or proxy. Off until you set them up in Settings. They change who can see your traffic. They do not make you anonymous.
  • Passwords. Saved passwords are encrypted with your operating system's secure storage.

Locking DASH

App Lock locks the whole browser with one password. Turn it on in Settings, Security, choose a password of 8 or more characters and an auto-lock time. DASH then locks when it starts, when you choose Lock DASH now (Ctrl+Alt+L), and after the idle time you chose. While locked, pages are hidden, sound is muted and shortcuts are ignored. Five wrong tries in a row start a wait that doubles each time. There is no back door: if you forget the password, the only way in is Erase and reset, which permanently deletes history, bookmarks, saved passwords, cookies, cache, the downloads list and sessions. Website Lock is separate and protects single websites, each with its own password.

Backups and moving your data

In Settings you can export a backup file and import it again, and import bookmarks and other data from another browser. Backups are files you choose where to save, and they are encrypted. Keep the password, because a backup cannot be opened without it. Your live data is in %APPDATA%\DASH on Windows.

On Android

  • Keeps playing with the screen off. A playing page keeps going when the screen is locked, with a media notification. Turn it off in Settings. It is off in Incognito. It is not tested on every phone, and sites such as YouTube may change how they detect hidden pages.
  • Tabs. Swipe a tab card sideways to close it (with Undo). Swipe the address bar left or right to switch tabs.

Fixing common problems

Windows says it protected my PC

That is SmartScreen, shown because the build is not code-signed yet. Choose More info, then Run anyway, but only for a file you downloaded from the official releases page. You can compare its SHA-256 with the one on the Download page when GitHub provides it.

A website is broken

Turn off tracker blocking for that site, or open it in a private tab to rule out saved cookies. If that fixes it, a blocked request was needed by the page.

DASH starts slowly

Slow starts are usually caused by a VPN or an extension that takes time to load. Every start writes a line to dash-startup.log in DASH's data folder. Start DASH with the environment variable DASH_TRACE_STARTUP=1 for a step-by-step trace, and attach the log when you report it.

I forgot my App Lock password

Use Erase and reset on the lock screen. It deletes your data in DASH, as described above. A backup you exported earlier can bring it back.

Uninstall

Remove DASH from Windows Settings, Apps. Your data folder is left in place so a reinstall finds it. Delete %APPDATA%\DASH if you want everything gone. On Android, uninstall the app like any other.

Still stuck?

Search the questions, or report a problem. Say which version you run and what you expected to happen. DASH is made by one person, so replies can take a few days.
