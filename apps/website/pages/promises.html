Most privacy claims ask you to take someone's word. These do not. Each promise below comes with a way to check it on your own computer, in a few minutes, without trusting me.

Updated {{updated}}. These are about the current release of DASH. The checks below are for Windows.

Sent

Nothing about you goes to the developer.

No analytics, no usage statistics, no crash uploads and no advertising ID. The developer runs no server that DASH reports to.

Check it yourself
  1. Open DASH and leave it on its new tab page.
  2. On Windows, search the Start menu for Resource Monitor and open it, then open the Network tab.
  3. Tick dash.exe in the list of processes. The TCP Connections box now shows every address DASH is talking to.
  4. Browse to a site, then compare. You should only see the sites you opened, plus the items on the Connections page that you switched on.
Stored

Your data stays on your device.

Browsing history, bookmarks, the downloads list, settings, notes and saved passwords are kept in one folder on your computer. Saved passwords are encrypted there.

Check it yourself
  1. Press Win + R, type %APPDATA%\DASH and press Enter.
  2. That folder is everything DASH keeps on Windows. Close DASH, rename the folder, and start DASH again: it starts empty, which shows nothing is stored anywhere else.
  3. Rename the folder back to restore your data.
Needed

DASH does not ask you to create an account.

You install it and use it. Signing in to a website, such as your email, is between you and that website. DASH has no sign-in of its own and no sync service.

Check it yourself
  1. Install DASH and complete the first-run setup.
  2. Look at what it asked for: a theme, a search engine and a few privacy choices. There is no email field and no password for DASH itself.
Listed

Every connection DASH can make is written down.

Apart from loading the pages you ask for, the only requests DASH makes are the ones on the Connections page. Each one is switched off by default or starts with something you do.

Check it yourself
  1. Do the Resource Monitor check above while using a feature from the list, such as secure DNS.
  2. The address that appears should be the one the list names. An address that is not explained by a site you opened or a feature you switched on is a bug.
Genuine

The file you download is the file that was published.

Every release has a SHA-256 checksum. If yours matches, nothing changed it on the way to you.

Check it yourself
  1. Follow the two-minute steps on the verify page.

What these checks cannot show

The code is public, so you can read it too, but reading is not the same as checking the app you actually installed. These checks watch what the installed DASH does, which is what matters for your privacy, but they cannot prove what it might do in some situation you did not test. Even if you build DASH yourself, you are trusting your own reading of a large codebase. They also do not cover Android, where the tools differ. Here is what is still true: the Windows build is not code-signed yet, DASH is made by one person, and large teams with public code get more outside review than DASH does.

If a promise is broken

If a check shows DASH doing something it says it does not, that is a bug and a serious one. Report it with what you saw, or use the private route on the security page if it could put people at risk.
