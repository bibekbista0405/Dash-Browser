DASH is built so that the developer learns nothing about you. This policy covers the DASH apps and this website. It does not cover the websites you visit with DASH.

Effective {{updated}}. Written by the developer, Bibek Bista, an independent developer in Nepal.

The short version

  • DASH has no telemetry, analytics, crash reporting or usage statistics. It sends nothing about you or your use of the app to the developer or anyone else.
  • DASH has no accounts and no sync service. There is nothing to sign in to.
  • Your history, bookmarks, downloads list, settings, notes, saved pages and saved passwords stay on your own device.
  • This website sets no cookies and runs no analytics.

What DASH stores, and where

Browsing history, bookmarks, the downloads list, settings, notes, saved offline pages and saved passwords are stored on your device. On Windows that is the folder %APPDATA%\DASH. Saved passwords are encrypted with the operating system's secure storage. Backups you export are files that you choose where to save. DASH uploads none of this anywhere.

Connections the desktop app makes by itself

Besides loading the sites you ask for, these are the only connections DASH for Windows makes. Each one is off by default, started by you, or goes to your own computer.

FeatureWhat is contactedWhen
Update checkThe https address you enter under Settings, UpdatesOnly if you turn automatic updates on
Secure DNSThe DNS provider you choose (Cloudflare by default when enabled)Only if you turn Secure DNS on. Your DNS lookups then go to that provider
VPN or proxyThe proxy server you configureOnly if you configure and turn it on
Check my IPapi.ipify.orgOnly when you press the button
Translate pagetranslate.google.com, with the page addressOnly when you choose Translate. Google then sees that page address
Search suggestionsYour chosen search engine (Google, DuckDuckGo, Bing or Brave), with the text you are typing, no cookiesOnly while you type in the address bar or on the New Tab page, and only if Show search suggestions is on. Never from a private tab
Install an extension from the Chrome Web Storeclients2.google.comOnly when you install an extension
AI helperA local Ollama server on your own computer (127.0.0.1)Only when you use it. Nothing is sent to an online AI service

Private tabs connect the VPN you set up (if that option is on) before they load anything, and wipe their cookies, storage and cache when the last private tab closes. A VPN changes who can see your traffic. It does not make you anonymous.

DASH for Android

DASH for Android follows the same rules: no telemetry, no accounts, no advertising IDs, and your data stays on the phone. Besides the sites you open, it can contact the search engine you choose (for results, and for suggestions while you type, never in Incognito) and Google Translate if you choose Translate. The app asks for permissions such as camera, microphone and location only so that websites you visit can ask for them, and each site still needs your approval. The Android app is newer than the desktop app and has been checked less. If you find it doing something not described here, please open an issue.

This website

  • No cookies, no analytics, no advertising, no tracking pixels.
  • Your browser keeps a few small settings for you in its own storage: the light or dark choice, whether you have seen the intro this session, and whether you hid the download bar. They never leave your device.
  • The page asks GitHub (api.github.com) for the latest release, the file sizes and the public download count. GitHub receives your IP address as part of that request and has its own privacy policy.
  • The page's fonts are served from this site itself. No other site is contacted to load them.
  • The Download buttons link straight to files on GitHub. The "what any website can read" section reads values from your own browser and shows them only to you. Nothing from it is sent anywhere.
  • Whoever hosts this site (for example Vercel) keeps its own technical server logs. The developer does not receive analytics from them.

Third parties

If you turn on Secure DNS, translate a page, install an extension, or use a search engine, the provider you chose receives the request described above and applies its own policy. DASH has no control over them.

Your rights

The developer holds no personal data about DASH users, so there is nothing to request, correct or delete. Your data is in files on your device, and you can export or delete it from DASH or by removing the data folder.

Children

DASH collects no personal data from anyone, including children.

Changes and contact

If this policy changes, the date at the top changes. Questions or concerns: report them here. The list of connections on the Connections page matches this policy; if DASH ever makes a request that is not listed, that is a bug.
