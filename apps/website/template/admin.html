Edit the website's text here. Nothing is uploaded: your changes stay in this page until you download the file. Then replace apps/website/content.json in the repository and the site rebuilds itself.

How publishing works. Commit the new content.json (or use "Edit on GitHub" and paste the copied JSON). The GitHub Action in .github/workflows/website.yml runs node apps/website/build.mjs and deploys the result to GitHub Pages. To preview locally, run node apps/website/build.mjs and open apps/website/dist/index.html.
