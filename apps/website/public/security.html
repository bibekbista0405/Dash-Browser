Security

Security

Only the latest release of DASH receives security fixes. If you find a problem, please tell us privately first.

Updated November 27, 2026.

Report a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead, so the details are not public before a fix exists. It needs a free GitHub account:

Report privately on GitHub

Include what you found, how to reproduce it, and the DASH version. DASH is maintained by one person, so replies can take a few days. You will be told whether the report is accepted and, if so, when a fix is released. Please allow time for a fix before you disclose publicly. If the link does not work, private vulnerability reporting may not be switched on yet; in that case open a public issue that says only "I have a security report" and no details.

Scope

In scope: DASH's own code, meaning the Electron main process, the preload bridge, IPC handlers, internal pages, storage and packaging. Out of scope: vulnerabilities in websites you visit, and in Electron or Chromium themselves. Report those upstream. DASH picks up fixes by updating Electron.

Design notes for researchers

  • Context isolation and sandboxed renderers are on.
  • IPC calls are validated and accepted only from DASH's own windows and bundled internal pages.
  • Saved passwords are encrypted with the operating system's secure storage.
  • App Lock stores only a salted scrypt verifier, never the password.
  • DASH has no telemetry. See the Privacy policy.

Check what you download

  • Download only from the official releases page. The Download page links straight to those files.
  • When GitHub shows a SHA-256 for a file, the Download page prints it. Compare it with the hash of your file (in PowerShell: Get-FileHash .\file.exe).
  • The Windows files are not code-signed yet, so SmartScreen warns on first run. Checking the SHA-256 on the verify page is the way to confirm the file until signing is in place. It does not claim signing exists today.
  • Android files are APKs. Only allow installs from your browser or file manager while you install, and turn the permission off afterwards.
