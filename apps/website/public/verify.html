Verify your download

A checksum proves the file you downloaded is the same file published on GitHub, byte for byte. It takes about a minute.

Updated November 25, 2026.

Why bother

The Windows installer is not code-signed yet, so Windows SmartScreen shows a warning the first time. Checking the SHA-256 checksum is how you confirm the file was not damaged or swapped on the way to you. It does not replace trust in the project: it only shows that your copy matches the one on the official GitHub release.

Find the official checksum

Open the latest release on GitHub. Each file listed under Assets shows a SHA-256 value. The download page on this site shows the same value when it can read it from GitHub. If the two ever differ, do not install and tell me.

On Windows

Open PowerShell in the folder with the file and run the command below. Replace the file name with the one you downloaded.

Get-FileHash .\DASH-Setup.exe -Algorithm SHA256

Compare the Hash value with the one on GitHub. Letter case does not matter. Every character must match.

On Android, Linux or macOS

sha256sum DASH.apk

On macOS use shasum -a 256 DASH.apk. On Android you can run the same command in a terminal app such as Termux.

Build it yourself

DASH is open source under GPL-3.0. If you would rather not trust a prebuilt file at all, you can read the code and build it from the repository. The build steps are in its README.

What a checksum cannot tell you

  • It cannot prove the code is safe, only that your file is the published one. The code is public so anyone can review it.
  • A checksum copied from a page that an attacker controls proves nothing, so always take it from the GitHub release page of this repository.
