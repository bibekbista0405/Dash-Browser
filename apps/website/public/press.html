Writing about DASH? Here are the facts, a short description and the logo, free to use for coverage.

Updated November 27, 2026.

Short description

DASH is a free browser for Windows and Android. It blocks ads and trackers, sends nothing about its users to the developer, needs no account and keeps data on the device. It is made by one developer, Bibek Bista, in Nepal.

Facts

  • Platforms: Windows 10 and 11 (64-bit), Android.
  • Price: free, no ads, no account.
  • Licence: source-available (PolyForm Noncommercial 1.0.0), free to use. See the terms.
  • Source code: github.com/bibekbista0405/Dash-Browser
  • Downloads: official releases
  • Code base: about 31134 lines in 241 files, counted when this site was built.
  • Developer: Bibek Bista, solo, about the developer.

Windows builds are not code-signed yet. Please say so if you write about installing it.
