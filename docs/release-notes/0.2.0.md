## DASH 0.2.0

A faster, calmer start on Windows, and a bigger Android app. No telemetry, no accounts, no ads. Your data stays on your device.

### What's new

**Windows**
- The window now opens once, fully painted, instead of appearing in pieces. It no longer waits for extensions or "connect VPN on startup" before showing.
- Steadier first frame on Windows (fixes black or stale frames on a newly shown window).
- Every start writes one line to `dash-startup.log`, so a slow start can be diagnosed. Nothing is sent anywhere.
- The About screen now shows the licence and links to the source code.

**Android**
- Bookmark folders, with search across all folders.
- Voice search and offline QR scanning in the address bar.
- Picture-in-picture for full-screen video, and background audio with a Stop button.
- Reading mode, Translate page, and hiding of cookie pop-ups.
- Music and podcasts keep playing with the screen off.
- Swipe a tab card to close it (with Undo), and swipe the address bar to switch tabs.
- A quieter three-page first-run setup.

**Licence**

Open Command Prompt in the folder with the file and run `certutil -hashfile "DASH Setup 0.2.0.exe" SHA256`. The result must match the SHA-256 listed below. Steps with screenshots: the Verify page on the website.

### Before you install

- **Windows** shows a "Windows protected your PC" screen because DASH is not code-signed yet. Check the SHA-256 above, then choose More info > Run anyway.
- **Android** asks you to allow installing from your browser or file manager the first time. If Android refuses to update an older install, save an encrypted backup first (Settings > Your data > Save encrypted backup), uninstall, then install this version and restore.

### Known limits

- The Windows build is not code-signed.
- The Android app is new and has been tested on few devices. Picture-in-picture, background audio, the QR scanner and voice search depend on your phone, so please report what does not work.
- DASH is built and tested by one person.

### Report a problem

Open an issue on this repository with your DASH version, Windows or Android, what you did and what happened. Security problems: see SECURITY.md and do not post them publicly.
